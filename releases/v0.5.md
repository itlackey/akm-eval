Larger public case sets, so one case moves a main metric by at most 2.5 points, and the fixes that let every eval run cleanly on akm 0.10.261003-beta. No eval changed version: nightly and reflect stay at 0.3, the rest at 0.2.

## What changed

- **Larger public sets.** Each main metric now rests on at least 40 cases. The cases that were there are unchanged, so they still compare with earlier runs:

  | eval | cases | main metrics now rest on |
  |---|---|---|
  | judge-gate | 106 → 135 | 40 good cases (was 11), 10 of them editing the body |
  | extract | 20 → 64 | 40 insight sessions, 20 routine |
  | distill | 38 → 96 | 40 behind `good_lessons`, 40 behind `lesson_updates` |
  | bakeoff | 15 → 40 | 8 per process |
  | reflect | 50 → 80 | 40 defects, 40 controls |
  | consolidate | 60 → 80 | 40 behind `recall` |
  | promotion | 20 → 80 | 40 good, 40 bad |

  The new cases are synthetic. They follow each eval's labelling rules and pass its checks, but no real-model run has checked them yet.
- **Semantic retrieval on akm 0.10.** curate abstains on a tool envelope such as retrieval's `n08` and returns no results and no `searchMode`. That is now an empty answer, not a failed semantic call, so the semantic run no longer aborts.
- **reflect on akm 0.10.** The six cases made from llm-delegation-tool's example agents and commands now sit in their type's folder, where akm reflects on them. All 50 of the old cases are scored again, not 44.
- **akm 0.10 is the pin.** The Harbor evals' default akm and the required smoke leg are akm-cli 0.10.261003-beta with plugin 0.10.261002-beta.
- **`model_calls` in every summary** of an eval that calls a model through akm:
  - `calls` and `errors`;
  - per successful call, the mean `prompt_tokens`, `completion_tokens` and `seconds`;
  - `output_tokens_per_second`.

  akm does not stream, so prefill and decode are not told apart.
- **promotion fix.** Two cases no longer share one memory file, which used to make one overwrite the other in a full run.
- **One toolchain install.** `@types/bun` and `typescript` are pinned once, in the root `package.json`. Only `scripts/ledger/src` keeps its own, for its browser test.

## After upgrading

1. **Run `bun install` at the root.** The src folders no longer have their own `package.json`.
2. **Make the custom corpora again** with `./generate-assets`, so `--corpus custom` includes the new cases.
3. **Run promotion's baseline again.** Its cases share one library, which grew, so every promotion case has a new input and no earlier promotion run compares. For the other evals, a comparison with a v0.4 run uses the cases both runs have, and names the rest.
4. **To keep the old default akm** in agent-ab or terminal-bench, pass `--akm akm-cli@0.9.26`.
