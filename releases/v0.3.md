A smaller akm-eval: the machinery that kept results comparable is replaced by a version you set by hand, and every comparison scores its runs again. No eval changed version, so runs made with 0.2 compare with runs made with 0.3.

## What changed

- **Versions are set by hand.** Each eval's `version` is in its `src/measurement.ts`. Change it when what the eval asks akm changes; runs of two versions are compared only with `--treatment harness`. `MEASUREMENT.lock`, `scripts/measurement`, the CI gate on digests and the golden tests are gone. MEASUREMENT_CHANGELOG.md lists version changes.
- **Every comparison rescores.** `scripts/compare` and the matrix score every stored run again with the current scorer and labels before they compare. A run they cannot score again (raw outputs missing, or cases outside the repository) is compared as it was scored, with a warning. `scripts/rescore` still writes a rescored folder by hand.
- **`--cases` asks first.** A run with `--cases DIR` shows the model and endpoint (and the judge) it will send your cases to and asks `Continue? [Y/n]`. `-y` or `--yes` skips the question. With no terminal and no `-y`, the run stops.
- **No corpus.json, no private flag.** A custom corpus is the rewrite in `private/<eval>/assets`, whose `generated.json` holds only the seed, or a folder you give with `--cases`. `run` takes a rewrite as it is: no generator digest is checked. A `models.json` line with `"private"` is refused. `--corpus private`, `own` and `own-feedback` stop with a message naming what to use.
- **`--repeat N` on longmemeval and skillret,** so every eval and benchmark repeats, and the matrix confirms them all.
- **Results made before 0.2 are refused** by compare, the matrix and rescore. They have no manifest.
- **An engine is its model and its endpoint's host.** Manifests no longer carry an endpoint id; older ones are read without it.
- **One redaction rule.** A config value is written as `<redacted>` when its key ends in key, token, secret, password, credential, authorization or cookie, or its last word is auth, bearer, pat or pass. `$NAME` references stay.
- **No coverage threshold.** A comparison uses the cases both runs gave the same input, however few, and names the ones it left out.
- **Shorter documents.** The README covers running, repeating and comparing; each eval's README covers that eval.

## After upgrading

1. **Run again any result made before 0.2.** It is refused now.
2. **Add `-y` where a script or a matrix row uses `--cases`.** Without a terminal the run stops at the question.
3. **Delete `"private"` from any `models.json` line,** and any `corpus.json` you kept: the first is refused, the second is ignored.
4. **Expect the first matrix stage to run every row again, once.** A row's resume fingerprint now holds the eval's version without the lock's digest, so no row recorded by 0.2 matches. `--stage screen --dry-run` shows what would run. Results from 0.2 still compare with the new ones.
