# Juniper translation glossary

The Juniper glossary lists 240 product terms with approved translations. A term is added by pull request to the glossary repository. Translators see the glossary inside the translation tool. Terms that must not be translated are marked with the flag keep. The glossary is reviewed by a native speaker for each language once a year.
