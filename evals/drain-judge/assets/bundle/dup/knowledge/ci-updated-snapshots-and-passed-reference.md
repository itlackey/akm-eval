---
description: "Resolving the CI snapshot update issue by removing the update flag and enforcing strict CI checks."
---

The frontend application experienced a three-week period where visual regressions in the header component remained undetected despite the presence of snapshot testing infrastructure. This oversight occurred because the continuous integration pipeline executed the Jest command with the update flag (`-u`). This specific flag instructs the testing framework to overwrite existing snapshot files whenever the current output diverges from the stored baseline, effectively masking the discrepancy. Consequently, the updated, incorrect snapshots were discarded along with the temporary build artifacts, preventing any failure signal. To rectify this, the pipeline configuration was modified to exclude the update parameter and instead utilize the `--ci` flag. This adjustment ensures that Jest terminates with an error code if a snapshot is missing or does not match the expected output, thereby catching the header layout defect immediately. Moving forward, snapshot modifications are restricted to local development environments, requiring manual review within pull requests to maintain visual integrity.
