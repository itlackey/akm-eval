description: "The mailing tool fills a merge field only from a column with exactly that name."
---

Merge fields match column names exactly: `{{first_name}}` is not filled from a column headed `First Name`, and the placeholder is sent as is, as 312 Larkspur readers saw. Rename the column to `first_name` and import again. The preview shows only the first contact, so it can look right when other rows are wrong.
