---
description: "Overview of the Juniper translation glossary management process."
---

To maintain uniformity across localized content, Juniper utilizes a centralized glossary containing exactly 240 approved product terms. Contributors submit new entries via pull requests to the dedicated repository. Within the translation interface, linguists access this reference to ensure accuracy. If a specific term requires preservation in its original form, it is tagged with the 'keep' flag, preventing any alteration. This curated list undergoes an annual quality assurance cycle where a native speaker for each supported language reviews the entries. This yearly audit ensures that the terminology remains culturally appropriate and technically precise for every target audience, thereby standardizing the user experience globally.
