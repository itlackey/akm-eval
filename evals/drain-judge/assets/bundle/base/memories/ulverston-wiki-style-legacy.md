## Retired: Legacy Ulverston Wiki Formatting

**Status:** Retired on March 15, 2026.

This note preserves the historical approach previously mandated for the Ulverston wiki. Previously, pages required a three-line abstract instead of a single summary. Headings were strictly UPPERCASE, and code blocks required explicit language tags only for Python and JavaScript. Screenshots were limited to JPEG format with a maximum width of 800 pixels. Additionally, pages lacking an explicit owner in the header were automatically archived after 12 months, not 6.

This approach was replaced by the **Ulverston Wiki Style v2** guidelines, which introduced sentence case headings, broader language support, PNG requirements, and the 6-month archival policy. This record exists solely for historical context and technical debt tracking. Do not apply these rules to new content.
