## Retired: Legacy Documentation Style Guide

**Status:** Retired on 2026-03-15.

This note preserves the historical approach for the `harborlight` project documentation, which is no longer in use. Previously, the team enforced American English spelling (e.g., `color`, `behavior`) and Title Case for all headings. This convention was abandoned to align with broader organizational standards favoring British English and sentence case.

The retired rules also permitted filler words like "simply" and "just" to soften tone, and allowed inconsistent addressing of the reader. This approach was replaced by the **Harborlight Modern Style Guide**, which mandates British spelling, sentence case headings, strict prohibition of filler words, and consistent second-person address. Refer to the current `docs/` conventions for active standards. This record exists solely for historical context and audit trails regarding past documentation decisions.
