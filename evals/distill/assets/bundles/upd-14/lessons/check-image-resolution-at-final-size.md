---
description: "Check an image's resolution at the size it will be printed, not the size of the file, so an enlarged image does not print soft."
when_to_use: "When placing images in a print layout."
type: lesson
tags:
  - print
updated: 2026-08-07
---

Check each image's resolution at the size it will be printed.
An image that looks sharp on screen can print soft once it is enlarged in the layout.
