The release notes for 2.5.0 had no links to pull requests. The changelog entries
had been written at release time from commit messages, and commit messages do
not carry pull request numbers. Adding the pull request number to each
changelog line when the change is merged, instead of at release time, fixed the
notes for 2.5.1.
