---
description: "Add the pull request number to the changelog entry when a change is merged, so that the release notes can link every change."
when_to_use: "When a change is merged into a project that keeps a changelog."
type: lesson
tags:
  - release
  - changelog
updated: 2026-09-12
---

Commit messages do not carry pull request numbers, so entries written at release
time cannot link them. Write the changelog line, with its pull request number,
at merge time.
