The invoice extraction prompt got three worked examples added, each an invoice
from Pellmark Supplies with its fields filled in. On a test set of 50 Pellmark
invoices, the share of fields extracted correctly rose from 71 percent to 84
percent. All 50 test invoices came from Pellmark, the same supplier as the
examples, so the result says nothing yet about the other suppliers, whose
layouts differ. The longer prompt added about 900 tokens to each call.
