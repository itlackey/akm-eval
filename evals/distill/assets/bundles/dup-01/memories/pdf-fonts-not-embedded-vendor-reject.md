The print vendor rejected the Tallowmere interior PDF because three fonts were
not embedded. The export had used the "smallest file" preset, which leaves some
standard fonts out. Exporting again with the "press quality" preset embedded
every font, and the vendor's preflight passed. The cover PDF, exported with the
same preset, had been rejected for the same reason.
