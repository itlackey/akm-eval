The Hollin Reach cover came back from the vendor's preflight with its blues
shifted toward purple. It had been exported with the default colour profile
instead of the vendor's own. The profile is set in the export dialog, under the
Output tab. Exporting again with the vendor's profile fixed the blues, and the
vendor accepted the file.
