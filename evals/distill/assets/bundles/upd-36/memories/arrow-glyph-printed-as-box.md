The printed Pinecrest field manual showed an empty box wherever the text had a
right arrow, 41 times in all. The arrows looked right in the source because the
editor substituted a system font, but the body font chosen for print has no
arrow glyph, and the PDF export did not substitute. Nobody had read the
exported PDF before it went to the printer. The arrows were replaced by the
word to, and the 200 copies were reprinted.
