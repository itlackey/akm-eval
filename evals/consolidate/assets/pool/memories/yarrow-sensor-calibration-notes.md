# Yarrow sensor calibration

Yarrow field sensors are calibrated every 6 months. The calibration uses the reference rig in the lab at Yarrow Hill. A sensor is accepted when it is within 0.5 percent of the reference. The result is written to the sensor record in the asset register. A sensor that fails twice in a row is retired. Calibration takes about 40 minutes for each sensor. The reference rig is itself checked by an outside lab every year.
