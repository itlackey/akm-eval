# Ashgrove onboarding week

A new Ashgrove hire gets a laptop on the first morning. The first day ends with a meeting with the team lead. Each hire is paired with a buddy for the first 4 weeks. Access requests for the main systems are filed before the start date. The hire ships a small change to production by the end of the first week. A feedback call with the manager happens on day 30. The security training must be done before access to production is granted.
