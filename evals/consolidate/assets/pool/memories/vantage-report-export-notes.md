# Vantage report export

Vantage reports can be exported as CSV or XLSX. An export covers at most 90 days of data. Exports run in the background and the user gets a link by email. The link works for 48 hours. Only users with the analyst role can export. Every export is written to the audit log. The export link can be opened only by the user who asked for it.
