About akm. It keeps a project's notes, documents and workflows in bundles. Each asset has a type (memory, knowledge, workflow and others) and a ref such as `memories/name`. A project is a directory registered in akm's configuration; run inside it, akm applies that project's defaults, and notes can carry a `project` field. Commands print JSON. Search returns refs; show opens one. To find your way, run `akm -h`, `akm help <command>`, or `akm hints` for a fuller guide. Read what a command printed before you rely on it.
