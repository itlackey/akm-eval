# Patient Vitals Charting

A consistent method for recording and reviewing vital signs so trends are
visible and abnormal values are not missed.

## The core vitals

1. **Temperature** — record the method used (oral, tympanic, axillary,
   rectal); each has a different normal range.
2. **Pulse** — rate, rhythm (regular/irregular), and strength.
3. **Respiratory rate** — count for a full 60 seconds when the rate is
   irregular or borderline.
4. **Blood pressure** — record cuff size used; an undersized cuff falsely
   elevates readings.
5. **Oxygen saturation (SpO2)** — note any supplemental oxygen in use, since
   it changes interpretation of the reading.

## Charting discipline

- Record vitals at the time they are taken, not from memory later.
- Chart the actual number, not just "normal" or "abnormal" — trends across
  readings are often more informative than any single value.
- Flag and escalate any value outside the patient's established normal
  range, even if it is within the general population reference range.
- Always note position (sitting/standing/lying) and activity immediately
  prior, since both affect pulse and blood pressure.

## Common pitfall

Charting a rounded or "typical-looking" number instead of the actual reading
hides early warning trends — write down what the device or count actually
showed.
