description: Old procedure for submitting e-filed returns through the discontinued vendor portal
beliefState: superseded
---
We used to submit e-filed individual returns through the legacy vendor's
batch-upload portal, queuing submissions overnight and confirming acceptance
the next morning. This workflow was replaced when the firm switched to
direct-transmission e-file software with same-day acknowledgments; do not
route new filings through the old batch portal, and don't reference this
procedure when onboarding new staff.
