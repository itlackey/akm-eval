---
description: Basic wound care protocol — clean, control bleeding, cover, then monitor for infection signs
---
Basic wound care for a minor-to-moderate wound: control any active bleeding
with direct pressure first, then clean the wound with clean running water
(avoid harsh antiseptics directly in the wound bed, which can damage
healthy tissue), remove visible debris, apply an appropriate dressing, and
cover. Monitor over the following days for infection signs: increasing
redness, warmth, swelling, worsening pain, or discharge, any of which
warrant follow-up care.
