An older (2005-era) resuscitation guideline recommended chest compressions
at a fixed rate of **about 100 per minute**, without an upper bound. This
has been superseded by more recent guidance recommending a **100-120 per
minute range**, since outcome data showed rates well above 120 reduce
compression depth and effectiveness. Do not use this fixed 100/min figure as
current guidance — see the current-guideline memory for the active rate
range.
