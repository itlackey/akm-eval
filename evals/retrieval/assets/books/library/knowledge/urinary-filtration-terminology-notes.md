# Renal Nephron Function Terminology

## Renal Nephron Function Basics

Renal nephron function is the term most reference materials use for the
combined filtration, reabsorption, and secretion work of the nephron.

## Renal Nephron Function And Hormonal Regulation

Renal nephron function also depends on hormonal regulation (aldosterone,
ADH) acting on the distal tubule and collecting duct.

## Renal Nephron Function Summary

In summary, renal nephron function integrates filtration, reabsorption, and
secretion into a single continuously operating unit, and renal nephron
function is the term most textbooks use for that combined process.
