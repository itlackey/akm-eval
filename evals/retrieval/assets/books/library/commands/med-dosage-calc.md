---
description: Show the arithmetic for a weight-based medication dose calculation as a general-education worked example
---
Given a medication's dose expressed per kilogram of body weight (e.g. "10
mg/kg") and a body weight, show the full worked calculation:

1. State the formula: `dose = rate_per_kg x weight_kg`.
2. Substitute the given numbers and show the multiplication step explicitly.
3. State the result with correct units, and round only after showing the
   unrounded intermediate value.
4. If the source rate has a stated maximum single dose, compare the
   calculated dose against it and flag if the calculated dose would exceed
   the maximum.

This produces a general-education arithmetic worked example only. It is not
a substitute for a pharmacist, prescriber, or verified dosing reference for
any actual patient.
