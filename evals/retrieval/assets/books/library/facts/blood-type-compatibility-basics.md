description: ABO/Rh blood type compatibility basics for transfusion — who can donate to and receive from whom
category: reference
---
The ABO and Rh(D) systems determine basic transfusion compatibility:

- **O negative** is the "universal donor" for red blood cells — it lacks A,
  B, and Rh(D) antigens, so it is least likely to trigger an immune
  reaction in a recipient of any blood type.
- **AB positive** is the "universal recipient" for red blood cells — it
  carries A, B, and Rh(D) antigens already, so it can receive from any ABO/Rh
  type without an antigen mismatch reaction.
- In general, a recipient's immune system reacts against donor red cell
  antigens it does not already carry — so a person can typically receive
  blood matching their own type, or a type lacking antigens they don't have
  (e.g. type O for anyone; Rh-negative for Rh-negative recipients).
- Plasma compatibility runs the opposite direction from red cell
  compatibility, since plasma carries antibodies rather than antigens
  (AB plasma is the universal plasma donor).

Actual clinical transfusion always requires crossmatching and lab
verification; this is general-education background, not a substitute for
that process.
