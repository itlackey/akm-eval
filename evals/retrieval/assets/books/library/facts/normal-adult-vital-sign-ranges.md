---
description: Reference ranges for normal adult resting vital signs (heart rate, blood pressure, respiratory rate, temperature, SpO2)
category: reference
---
General reference ranges for a healthy resting adult (individual baselines
vary; these are population reference ranges, not diagnostic thresholds):

- **Heart rate (pulse)**: 60-100 beats per minute at rest.
- **Blood pressure**: approximately 90/60 to 120/80 mmHg.
- **Respiratory rate**: 12-20 breaths per minute at rest.
- **Body temperature**: approximately 36.1-37.2 °C (97-99 °F), oral
  measurement.
- **Oxygen saturation (SpO2)**: 95-100% on room air.

A single reading outside these ranges is not automatically abnormal for a
given individual — trend and context (activity, medication, baseline)
matter. These are general-education reference values, not a diagnostic
tool.
