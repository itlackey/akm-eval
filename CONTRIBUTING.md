# Contributing to akm-eval

Development setup, pack requirements, the trust-policy checklist, and the
required validation commands are documented in
[`docs/contributing.md`](./docs/contributing.md).

Please read [`docs/comparability.md`](./docs/comparability.md) before changing
a benchmark, dataset, evaluator, sampling rule, or published result. Those
changes can invalidate comparisons even when the code itself is correct.
