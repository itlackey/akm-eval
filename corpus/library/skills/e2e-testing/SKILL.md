# E2E Testing Skill

End-to-end testing tools and patterns for comprehensive application testing.

## Sub-skills

### app-exploration
Application behavior exploration and analysis.

- **Purpose:** Explore and analyze application behavior, workflows, and user interactions to identify selectors, states, and navigation paths.
- **Use when:** You need to understand application behavior before writing tests or exploring workflows.

### test-implementation
End-to-end test implementation and execution.

- **Purpose:** Create and run end-to-end tests for complete application workflows using supported frameworks (e.g., Playwright, Cypress, Selenium).
- **Use when:** You need to implement comprehensive tests covering full user journeys from start to finish.

### references
Testing references, patterns, and best practices.

- **Purpose:** Access testing documentation, common anti-patterns, and best practice references for stable test design.
- **Use when:** You need guidance on testing strategies, patterns, or best practices to ensure maintainability.

## Quick Start

Each sub-skill has its own documentation. See the respective directories for detailed setup and usage patterns.

## Common Workflows

1. **Exploration:** Use `app-exploration` to understand application behavior, identify dynamic elements, and map user journeys.
2. **Test Creation:** Use `test-implementation` to write end-to-end tests that cover full user journeys.
3. **Reference:** Consult `references` for testing patterns and best practices when encountering flakiness or fragility.
