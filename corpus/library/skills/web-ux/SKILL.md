# Web UX Skill

Web user experience analysis, design review, and interface improvement tools.

## Sub-skills

### ux-dom-audit
UX and DOM structure audit.

- **Purpose:** Analyze DOM structure, accessibility, performance, and user experience
- **Use when:** You need to audit web interfaces, identify UX issues, or analyze accessibility problems

## Quick Start

The sub-skill has its own documentation. See the respective directory for detailed setup and usage patterns.

## Common Workflows

1. **UX Audit:** Use ux-dom-audit to evaluate user experience and interface quality
2. **Accessibility Review:** Use ux-dom-audit to identify accessibility issues
3. **Performance Analysis:** Use ux-dom-audit to analyze DOM performance
4. **Interface Improvement:** Use insights from ux-dom-audit to improve interface design
