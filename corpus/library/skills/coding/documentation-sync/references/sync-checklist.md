# Documentation Sync Checklist

- README and contribution commands
- Architecture diagrams and dependency rules
- API, schema, event, and configuration references
- CLI help, flags, examples, and environment variables
- Generated references and their source templates
- Tutorials, snippets, sample applications, and fixtures
- Deprecation, migration, compatibility, and support statements
- Operations, deployment, security, and performance guidance
- Code comments that state contracts rather than implementation trivia

For each changed claim, cite implementation or test evidence. Do not update a
generated file directly or describe a behavior that is only planned.
